Demander une analyse

Proposez un film en deux minutes : le formulaire vérifie d'abord si le film est déjà analysé sur le site — si oui, il vous donne le lien ; sinon, votre demande rejoint une file d'attente publique, où chacun peut suivre son étape.

La règle du jeu est simple et affichée sur le formulaire : votre demande apparaîtra dans la file publique, mais votre adresse et vos commentaires n'y apparaîtront jamais. L'arbitrage est humain : aucune analyse n'est générée ni publiée automatiquement.

Ouvrir le formulaire de demande

Voir la file des demandes — les propositions reçues, classées par étape.

Le formulaire et la file sont hébergés sur un service dédié (demande.cdatso.be) ; le site que vous lisez reste, lui, entièrement statique.

Vous préférez l'email ?

Écrivez-nous à analyses@cdatso.be — précisez le titre du film, le ou la réalisateur·rice, et si possible l'année de sortie (utile en cas de remake ou de plusieurs versions).
